Validation record

This package was built as a sequence of validation gates: each gate is a bounded claim about equivalence with the reference implementation, together with the measurements that support it, the deviations that were found, and what was deliberately left out of scope. These documents are the primary evidence behind every "validated" statement in the README — kept in the repository so that any claim can be traced to what was actually checked, per the provenance rule in ../building.md.

They are working records, in chronological order, and read like it: raw numbers, dead ends, and corrections included. That is intentional — a validation trail that only shows successes is not a validation trail.
