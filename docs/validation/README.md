# Validation record

This package was built as a sequence of **validation gates**: each gate is a
bounded claim about equivalence with the reference implementation, together
with the measurements that support it, the deviations that were found, and
what was deliberately left out of scope. These documents are the primary
evidence behind every "validated" statement in the README — kept in the
repository so that any claim can be traced to what was actually checked,
per the provenance rule in [`../BUILDING.md`](../BUILDING.md).

They are working records, in chronological order, and read like it: raw
numbers, dead ends, and corrections included. That is intentional — a
validation trail that only shows successes is not a validation trail.

| Gate | Claim | Record |
|---|---|---|
| FJ1 | package skeleton, typed data model, config hierarchy | [FJ1_STATUS.md](FJ1_STATUS.md) |
| FJ2 | semantic parity of the pure functions against fixtures from the Python source | [FJ2_STATUS.md](FJ2_STATUS.md) |
| FJ3 | native dynamics, observers, transition, exact NumPy RNG | [FJ3_STATUS.md](FJ3_STATUS.md) |
| FJ4 | the POMDPs.jl model interface | [FJ4_STATUS.md](FJ4_STATUS.md) |
| FJ5 / FJ5-R | live reference backends + matched-state one-step parity | [FJ5_STATUS.md](FJ5_STATUS.md), [FJ5R_STATUS.md](FJ5R_STATUS.md) |
| FJ6 | free-running full-episode rollout parity | [FJ6_STATUS.md](FJ6_STATUS.md) |
| FJ7 | the four trained baselines, matched layer by layer | [FJ7_STATUS.md](FJ7_STATUS.md) |
| FJ8 | online planning: solver contract, budget curves, comparison | [FJ8_STATUS.md](FJ8_STATUS.md), [FJ84C_STATUS.md](FJ84C_STATUS.md) |
| FJ9 | scientific visualization through reproducibility closure | [FJ9_STATUS.md](FJ9_STATUS.md), [FJ96](FJ96_STATUS.md), [FJ97](FJ97_STATUS.md), [FJ98](FJ98_STATUS.md), [FJ99](FJ99_STATUS.md) |
| FJ10 | POMDP readiness audit | [FJ10_STATUS.md](FJ10_STATUS.md) |
